# Технологии

Язык программирования: Java 11
WebDriver: Selenium WebDriver 4.15.0
Браузеры: Chrome, Yandex Browser

# Примеры запуска

#### Для запуска тестов в хроме Windows(Powershell) - `$env:BROWSER="chrome"; mvn clean test`

#### Для запуска тестов в яндекс браузере Windows(Powershell) - `$env:BROWSER="yandex"; mvn clean test`

#### Для запуска тестов в хроме Windows (Command Prompt) -
`set BROWSER=chrome;
mvn clean test`

#### Для запуска тестов в яндекс браузере Windows (Command Prompt) -
`set BROWSER=yandex;
mvn clean test`
